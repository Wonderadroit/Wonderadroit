# Skills and Evidence Matrix

This is an evidence log, not a self-rating contest. Update a level only when there is a practical demonstration or independently reviewable artefact.

## Level definitions

- **Unassessed:** no meaningful evidence reviewed.
- **Foundational:** can explain core concepts and complete guided tasks.
- **Working:** can complete common tasks independently and troubleshoot ordinary failures.
- **Strong:** can design, test, explain, and review non-trivial work independently.
- **Specialist:** sustained, externally validated depth in a defined subdomain.

## Rule
